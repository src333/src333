### 📱 [Decentralised Mosque Donation Platform](https://github.com/src333/web3-Crowdfunding-Application)
**Final Year Dissertation** | *Next.js, React, Solidity, Ethers.js, Hardhat, TailwindCSS*
> [💻 View Code](https://github.com/src333/web3-Crowdfunding-Application)

* Developed a full-stack Web3 crowdfunding platform for mosque donations using **Solidity smart contracts, Next.js, React, and Ethers.js**.
* Implemented secure donation flows with **MetaMask integration**, real-time Ethereum transaction ledger, and role-based admin control via Web3 authentication.
* Applied **Blockchain-Oriented Software (BOS)** methodology to separate on-chain and off-chain logic, ensuring modular and scalable architecture.
* Built an admin dashboard with campaign analytics, soft deletion, donation timelines, and live transaction visualisation using **Recharts.js**.
* Prioritised transparency and accessibility through a public ledger UI, educational onboarding pages, and mobile-first, responsive design using **TailwindCSS**.
* Conducted unit and integration testing using **Hardhat**, ensuring smart contract security, reentrancy protection, and access control integrity.
* Followed **Object-Oriented Analysis & Design (OOAD)** principles, using UML diagrams (class, state, deployment, and use-case) to guide system architecture and development.
